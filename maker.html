BSShub Mod Maker

Build a mod, copy the code, put it in a file on GitHub. Anyone can add it with the file's https link in BSShub's Mods tab.

1. About your mod

2. Add pieces

3. Your mod file

Name the GitHub file like my-cool-mod.js. Its link will be https://cdn.jsdelivr.net/gh/TheArmadilloKing/BSS-Multiplayer-Servers@main/my-cool-mod.js

  
Submitting opens GitHub (you need a free GitHub account). Press Submit new issue there. The store owner checks every mod before it goes live.
